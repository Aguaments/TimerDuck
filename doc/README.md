# TimerDuck
Deaktop timer with a duck image.

## Target
1. Create a timer on desktop
2. Use a duck image
3. Click the duck image can alert function tabs
4. Functions:
  - **Alarm Clock**:
    - <font color="#881188">User can set time duration</font>
    - <font color="#881188">Util the time duration to the end, the duck will play a song to remind user</font>
    - <font color="#881188">User can manipulate to stop the music</font>
    - <font color="#881188">User can manipulate to stop the alarm clock</font>
  - **Click**
    - <font color="#118811">Different click times while display different action of the duck</font>
    - <font color="#661188"><strong>Action 1: </strong>shake ass</font>
    - <font color="#661188"><strong>Action 2: </strong>angry(touch many times)</font>
    - <font color="#661188"><strong>Action 3: </strong>cry(over two hours)</font>

# Complie
1. use cmake to complie the project.

# Usage
1. choose a music and rename to "test1.mp3".
2. put the music to the "/bin" directory
